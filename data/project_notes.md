# Project notes

This learning demo has the internal codename Blue Heron. It was started
in October 2026 to practise building a small RAG pipeline and an MCP
server on Windows.

The first design review for Blue Heron is scheduled for 12 November
2026. The review will cover the retrieval quality and the MCP tool
design.

The project uses Python 3.14 in a virtual environment, with Groq for
the language model and Chroma for the vector database.
